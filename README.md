# Pedal preset controller

Firmware for the output part of a guitar-pedal preset controller. It runs on the STM32F407G-DISC1 board and is written in C with STM32CubeIDE and the ST HAL.

This was my part of a group project in DTEK8146 Embedded System Design at the University of Turku, 2026. The whole design and the task split are in [docs/Pedal_Arch_Task_Split.pdf](docs/Pedal_Arch_Task_Split.pdf). This repository holds the outputs part: the digital potentiometer driver, the LEDs, the button and a demo loop.

## Status

Done and tested on the board:

- SPI2 driver for three MCP41010 digital potentiometers. The SPI bytes were checked with a logic analyzer in PulseView.
- Board LEDs: power, preset and an unsaved-edit signal.
- User button B1 with debounce, short press and long press.
- A demo loop that ties these together.

Not done yet:

- The MCP41010 chips are not wired to the board yet.
- No physical knobs (ADC input).
- Saving presets.

## Demo

After reset the board runs an LED self-test, then starts in live mode with all three pots at mid value (2048, sent as byte 0x80).

- Press B1 for under 1 s: standby on or off. In standby the green LED dims and the pots are shut down.
- Hold B1 for 3 s: next mode, live -> preset 1 -> preset 2 -> live. Each mode sends its own three test values to the pots.

| LED | Pin | Meaning |
|---|---|---|
| Green | PD12 | power: full on, or dimmed in standby (PWM on TIM4 channel 1) |
| Orange | PD13 | preset 1 |
| Red | PD14 | preset 2 |
| Blue | PD15 | preset edited and not saved, three fast blinks on save |

## Wiring

| Signal | Pin |
|---|---|
| SPI2 SCK | PB13 |
| SPI2 MOSI | PB15 |
| Pot 1 / 2 / 3 chip select | PD8 / PD9 / PD10 |
| Button B1 | PA0 (board user button) |

SPI2 runs in mode 0 (clock idle low, data read on the first edge), 8-bit, MSB first, with a clock prescaler of 64. Each message is two bytes, sent while that pot's chip select is low:

- `0x11, value`: write pot 0 (MCP41010 datasheet, section 5.1).
- `0x21, 0x00`: shut the pot down (section 5.3).

Values come in as 0 to 4095, the same range as the 12-bit ADC. The driver drops the 4 lowest bits to get the pot's 8-bit value.

## Code

| File | What it does |
|---|---|
| `Core/Src/digipot.c` | MCP41010 driver: set a value, standby and back |
| `Core/Src/leds.c` | LED states and the non-blocking save blink |
| `Core/Src/buttons.c` | B1 debounce (20 ms), short press (< 1 s), long press (3 s) |
| `Core/Src/demo.c` | demo loop: LED self-test, standby, mode change |
| `Core/Inc/pedal.h` | shared types: events, modes, power states, presets |

The rest of the project is generated by STM32CubeMX 6.15.0. The pin and peripheral setup is in `pedal_controller.ioc`.

## Build

1. In STM32CubeIDE: File -> Import -> Existing Projects into Workspace, then pick the `pedal_controller` folder.
2. Build the project.
3. Flash and run it over the board's onboard ST-LINK.
